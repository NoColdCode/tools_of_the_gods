Tools of the Gods - FTB Quests defaults

This project now includes a default FTB Quests chapter at:
- defaultconfigs/ftbquests/quests/data.snbt
- defaultconfigs/ftbquests/quests/chapters/tools_of_the_gods.snbt

How to use:
1. Ensure FTB Quests is installed in the modpack.
2. Copy this mod/project into the pack or keep these files in the pack's defaultconfigs.
3. Start world and run /ftbquests reload (or restart game/server).
4. If quest IDs are regenerated by your FTB version, open FTB Quests editor once and save.

Quest line included:
- Crude -> Primal Pickaxe -> full tool arsenal
- Orb collection and trait remover milestone
- Ultimate Tool of the Gods finale
