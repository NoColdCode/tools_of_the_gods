# FTB Quests

This project includes default FTB Quests files under:

- `defaultconfigs/ftbquests/quests/data.snbt`
- `defaultconfigs/ftbquests/quests/chapters/tools_of_the_gods.snbt`

## Chapter included

- Chapter id: `tools_of_the_gods:chapter_main`
- Title: `Tools of the Gods`
- Subtitle: `From Crude to Ultimate`

## Quest flow

- Crude Awakening
- Primal Core
- Hammer Time
- Woodcutter of the Gods
- Earth Shaper
- Harvest Whisperer
- Edge of Divinity
- Bow of Fate
- Orb Scholar (gem milestone quest)
- Trait Surgeon
- Ultimate Ascension

## Included quest rewards

- Early XP and utility rewards
- Final quest XP reward: `2500`

## Usage notes

1. Install FTB Quests in the modpack.
2. Keep these files in pack `defaultconfigs`.
3. Start world and run `/ftbquests reload`.
4. If your FTB version rewrites ids, open quest editor and save once.
