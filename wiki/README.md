## Quick facts

- Standard TOG tools (pickaxe, hammer, axe, shovel, hoe, sword): max level `100`, max tier `9`.
- Bow: max level `50`, max tier `4`.
- Tier upgrades are gated every 10 levels.
- Ultimate Tool **power** modes: `Balanced`, `Precision`, `Overdrive`.
- Ultimate Tool **tool** modes: radial wheel (default key `G`), 11 weapon/tool types.
- Armor uses **Divine** material (`motion_of_the_gods`); wings use **Aerial** (no iron chestplate overlay).
- Expanded tools: fishing rod, crossbow, trident, staff, wings — each with exclusive traits.
